# Crumbl: The Journey of a Cookie (website concept)

A scroll-driven story site pitched as a concept for Crumbl Cookies.
Not affiliated with or endorsed by Crumbl. All illustrations, cookies and 3D are generated in code.

```
npm install
npm run dev      # http://localhost:5173
npm run build
```

Sections: bite-by-bite loader · 3D cookie that breaks apart · the cousins' road trip through the story ·
pinned kitchen journey (gather, mix, scoop, bake, frost, box) · weekly menu · 3D pink box · Crumbl today · finder · crumb wordmark footer.
